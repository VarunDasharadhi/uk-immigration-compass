# 2026-09-24

## Archive indexing checkpoint

Authenticated Google Search Console evidence covers one affected URL, `/updates/archive`. Its
status is `Discovered - currently not indexed`, first detected on 5 September 2026, with last
crawled shown as N/A. Validation was already `Started` before this work.

The deployed raw response for `/updates/archive` was an empty generic SPA shell with homepage
metadata. Archive metadata and content appeared only after JavaScript ran. This is the main
technical risk to investigate, not a proven cause: last crawled N/A means Google had not yet made
a normal crawl judgement about the URL.

The architecture judgement selected route-specific prerender with full confidence. The freshness
hybrid had lower confidence, so the implementation uses the smallest build-time snapshot and
records its freshness ceiling.

## Changes and local evidence

The application changes cover routing and presentation in `App.tsx`, `NewsDashboard`,
`PageHero` and `UpdatesArchivePage`, and client metadata in `utils/seo.ts`. The build path uses
`index.html`, `package.json` and `scripts/generate-archive-prerender.mjs`. The new
`utils/seo.test.ts` and `scripts/generate-archive-prerender.test.ts` cover client metadata and the
static generator.

The local build generated `dist/updates/archive/index.html`. It contains archive-specific initial
metadata, one H1, up to 20 escaped static items, CollectionPage and ItemList JSON-LD when records
exist, and a no-items fallback that keeps the build successful. Sitemap freshness uses only a
build-bounded `createdAt` or a genuinely later `updatedAt`, with build time as the fallback. The
visible event date remains separate from that freshness value.

Security and failure-mode coverage includes HTML and JSON escaping, non-HTTP source URL rejection,
future source timestamps being ignored, hydration order matching, FAQ schema being absent outside
the homepage News view, graceful fallback for malformed or unavailable archive data, safe build
time handling for an invalid epoch, and unrelated sitemap entries remaining unchanged.

The complete local gate passed: 19 suites, 127 tests, type-check, lint, build, Node syntax check,
generator black-box tests and diff check.
